# Amber potion game prop

Create a single amber potion bottle icon for a fantasy inventory grid.
This example supplies its own written art direction. It is not a default style
for other requests.

- Canvas: 512 × 512, transparent background.
- Composition: centered, all artwork inside a 40 pixel margin.
- Style: clean illustrated vector, soft glass gradients, dark plum outline.
- Perspective: front view, centered upright bottle, no visible isometric side face.
- Edges and light: 8 pixel outline at export size, smooth curves, upper-left
  light, cream highlights along the left glass edge; no pixel grid.
- Shape: squat round glass bottle, narrow neck, cork stopper, small hanging tag.
- Palette: amber liquid #D89129, mint glass edge #B4D8C0, plum outline #39263F,
  cream highlights #FFF1CF; derive gradient shades from these material colors.
- Detail density: one large label/tag and a few broad reflections; no tiny ornaments.
- Acceptance: recognizable at 64 × 64; continuous bottle silhouette; clearly
  visible cork and amber liquid; no text, scenery, watermark, or clipping.
- Deliver an editable self-contained draw.ts executed with Bun, SVG, and PNG preview.
